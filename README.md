# 민티의 맥북 & 클로드코드 가이드

> 비개발자 민티가 맥북과 클로드코드를 배우며 정리하는 실전 가이드

## 이 가이드는

- **맥북 기본기** - 윈도우와 다른 맥의 철학, 핵심 사용법
- **터미널 & iTerm2** - 터미널이 뭔지부터 iTerm2 활용까지
- **클로드코드** - 설치부터 실전 워크플로우까지
- **Git** - 비개발자를 위한 Git 기초

를 다루고 있다.

## 사용법

왼쪽 사이드바에서 카테고리별로 탐색하거나, 상단 검색으로 원하는 내용을 찾으면 된다.
