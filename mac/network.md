# 네트워크 & 인터넷 속도

> 인터넷이 느릴 때 진단하는 법, DNS 설정으로 속도 올리는 법

## DNS가 뭔데?

전화번호부 같은 거다. 우리가 `naver.com`을 입력하면 컴퓨터는 그게 무슨 뜻인지 모른다. 진짜 주소는 `223.130.200.107` 같은 숫자(IP)인데, 이걸 매번 외우긴 어려우니까 **DNS 서버**가 "naver.com → 223.130.200.107" 이런 식으로 변환해준다.

**DNS가 느리면 = 전화번호부 두꺼운 책 뒤지는 게 느린 거.** 사이트 자체는 멀쩡한데 주소를 못 찾아서 로딩이 느리게 느껴진다.

## 기본 DNS는 인터넷 회사(KT/SKT/LG) 거

별도 설정 안 하면 우리집 와이파이는 인터넷 회사가 정해준 DNS를 쓴다. 근데 이게 가끔 느리거나 불안정하다.

**대안:** 무료로 더 빠른 DNS가 있다.

- **Cloudflare**: `1.1.1.1`, `1.0.0.1` (제일 빠름, 추천)
- **Google**: `8.8.8.8`, `8.8.4.4`

## 맥 시스템 DNS 바꾸기

한 번 바꿔두면 **모든 앱(크롬, 사파리, 엣지, 앱스토어, 메일 등)이 다 빨라진다.**

### 방법 1: 시스템 설정에서 (GUI)

1. 시스템 설정 → Wi-Fi
2. 연결된 와이파이 옆 "세부사항"
3. DNS 탭
4. `+` 버튼으로 다음 4개 추가:
   - `1.1.1.1`
   - `1.0.0.1`
   - `8.8.8.8`
   - `8.8.4.4`
5. 확인

### 방법 2: 터미널에서 (한 줄)

```bash
# DNS 설정
networksetup -setdnsservers Wi-Fi 1.1.1.1 1.0.0.1 8.8.8.8 8.8.4.4

# 설정 확인
networksetup -getdnsservers Wi-Fi

# DNS 캐시 비우기 (즉시 적용)
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder
```

`sudo`는 관리자 권한이 필요하다는 뜻. 비밀번호 물어보면 **맥 로그인 비번** 입력. 입력해도 화면에 점/글자 안 보이는 게 정상.

### 원래대로 돌리기

```bash
networksetup -setdnsservers Wi-Fi empty
```

## 브라우저 인터넷 느릴 때 진단법

### 1. "전체 인터넷이 다 느림" → 네트워크/DNS 문제

- 와이파이 다른 거 잡아보기
- 위에서 한 것처럼 시스템 DNS 바꾸기
- 공유기 재부팅

### 2. "특정 브라우저만 느림" → 브라우저 설정 문제

같은 와이파이에서 크롬은 빠른데 엣지만 느린 식.

**체크할 것:**
- **확장 프로그램**: 광고 차단기/번역기 등이 충돌. 다 끄고 테스트.
- **쿠키/캐시 누적**: `Cmd + Shift + Delete`로 캐시 삭제.
- **보안 DNS(DoH) 설정**: 브라우저마다 자체 DNS를 쓰는 옵션이 있음. 시스템 DNS랑 충돌하면 끄는 게 나음.
  - 엣지: 설정 → 개인정보, 검색 및 서비스 → 보안 DNS → "현재 서비스 공급자 사용" 또는 끄기
  - 크롬: 설정 → 개인정보 보호 및 보안 → 보안 → 보안 DNS 사용

### 3. "특정 사이트만 느림" → 사이트 또는 계정 문제

예: 크롬에서 Google Flow만 느린데 다른 사이트는 빠르다.

**체크할 것:**
- **시크릿 창**(`Cmd + Shift + N`)에서 열어보기 → 빠르면 확장프로그램이나 쿠키 문제
- **다른 브라우저 프로필**로 열어보기 → 빠르면 계정/세션 문제
- **다른 브라우저**로 열어보기 → 거기도 느리면 그 사이트 서버가 느린 거

### 4. 크롬 자체 DNS 캐시 비우기

크롬은 시스템과 별도로 자체 DNS 캐시를 갖고 있다. 가끔 꼬일 때:

1. 주소창에 `chrome://net-internals/#dns` 입력
2. "Clear host cache" 버튼 클릭

엣지도 똑같이 `edge://net-internals/#dns`.

## 정리

| 증상 | 원인 가능성 | 해결 |
|------|-------------|------|
| 모든 앱 다 느림 | DNS, 와이파이 | 시스템 DNS 변경, 공유기 재부팅 |
| 특정 브라우저만 느림 | 확장/캐시/DoH 설정 | 시크릿 모드 테스트 → 캐시/확장 정리 |
| 특정 사이트만 느림 | 쿠키, 계정 세션 | 시크릿 창, 다른 프로필로 비교 |

**한 번 시스템 DNS만 Cloudflare로 바꿔두면** 일상에서 체감되는 인터넷 속도가 확실히 빨라진다. 무료고 안전하니까 추천.
