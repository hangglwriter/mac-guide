# 핵심 단축키

> 맥에서 자주 쓰는 단축키 모음

## 기본 조작

| 단축키 | 기능 | 윈도우 대응 |
|--------|------|------------|
| Cmd + C | 복사 | Ctrl + C |
| Cmd + V | 붙여넣기 | Ctrl + V |
| Cmd + X | 잘라내기 | Ctrl + X |
| Cmd + Z | 실행취소 | Ctrl + Z |
| Cmd + Shift + Z | 다시실행 | Ctrl + Y |
| Cmd + A | 전체선택 | Ctrl + A |
| Cmd + S | 저장 | Ctrl + S |
| Cmd + F | 찾기 | Ctrl + F |

## 앱 & 창 관리

| 단축키 | 기능 |
|--------|------|
| Cmd + Q | 앱 완전 종료 (윈도우에는 없는 개념) |
| Cmd + W | 현재 창/탭 닫기 (앱은 살아있음) |
| Cmd + N | 새 창 열기 |
| Cmd + T | 새 탭 열기 |
| Cmd + Tab | 앱 간 전환 (Alt+Tab과 동일) |
| Cmd + ` | 같은 앱의 창 간 전환 |
| Cmd + M | 창 최소화 (Dock으로 내리기) |
| Cmd + H | 현재 앱 숨기기 |
| Cmd + Option + Esc | 강제 종료 (Ctrl+Alt+Delete 역할) |

## Spotlight & 검색

| 단축키 | 기능 |
|--------|------|
| Cmd + Space | Spotlight 검색 (앱 실행, 계산, 검색 다 됨) |

Spotlight은 맥의 핵심 기능이다. 앱 이름 입력하면 바로 실행, 계산기 대신 숫자 입력하면 계산, 파일 검색도 가능.

## 스크린샷

| 단축키 | 기능 |
|--------|------|
| Cmd + Shift + 3 | 전체 화면 캡처 |
| Cmd + Shift + 4 | 영역 선택 캡처 |
| Cmd + Shift + 4 → Space | 특정 창 캡처 |
| Cmd + Shift + 5 | 캡처 도구 열기 (녹화도 가능) |

> 기본 스크린샷보다 [Shottr](https://shottr.cc/) 앱이 훨씬 편하다. 스크롤 캡처, 텍스트 인식(OCR), 주석 등 지원.

## 텍스트 편집

| 단축키 | 기능 |
|--------|------|
| Fn + Delete | 커서 오른쪽 삭제 (윈도우 Delete) |
| Delete | 커서 왼쪽 삭제 (윈도우 Backspace) |
| Cmd + 좌/우 | 줄의 처음/끝으로 이동 (Home/End) |
| Cmd + 위/아래 | 문서의 처음/끝으로 이동 |
| Option + 좌/우 | 단어 단위 이동 |
| Option + Delete | 단어 단위 삭제 |
| Shift + 방향키 | 텍스트 선택하며 이동 |
| Cmd + Shift + 좌/우 | 줄 전체 선택 |

## 파인더(Finder) 전용

| 단축키 | 기능 |
|--------|------|
| Cmd + Shift + G | 경로 직접 입력해서 이동 |
| Cmd + Option + V | 이동 붙여넣기 (Cmd+C 후 사용, 잘라내기 대용) |
| Cmd + Delete | 파일 휴지통으로 보내기 |
| Space | 파일 미리보기 (Quick Look) |
| Cmd + Shift + . | 숨김 파일 보기/숨기기 |
| Enter | 파일 이름 변경 (윈도우의 F2) |
| Cmd + 아래 | 폴더 열기 / 파일 실행 |

> **주의**: 파인더에서 Enter는 "열기"가 아니라 "이름 변경"이다! 윈도우 습관으로 Enter 누르면 이름이 바뀌어버림.
