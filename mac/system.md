# 시스템 설정 & 관리

> 맥북 시스템 환경설정, 저장공간 관리, 업데이트 등

## 시스템 설정 열기

- **Cmd + Space** → "시스템 설정" 검색
- 또는 좌측 상단 Apple 로고 → 시스템 설정

## 알아두면 좋은 설정들

### 트랙패드 설정
- 시스템 설정 → 트랙패드
- **탭하여 클릭**: 꾹 누르지 않고 터치만으로 클릭 (켜는 걸 추천)
- **자연스러운 스크롤**: 끄면 윈도우처럼 스크롤 방향 반대로

### 키보드 설정
- 시스템 설정 → 키보드
- **키 반복 속도**: 빠르게 설정하면 Delete 연타할 때 빠르게 지워짐
- **한영 전환**: Caps Lock 키 또는 Cmd + Space (설정에 따라 다름)

### Dock 설정
- 시스템 설정 → 데스크톱 및 Dock
- **자동으로 Dock 가리기**: 화면이 좁을 때 유용
- **크기 조절**: Dock 아이콘 크기 변경

## 저장공간 관리

```bash
# 터미널에서 디스크 사용량 확인
df -h
```

- Apple 로고 → 이 Mac에 관하여 → 저장공간 에서도 확인 가능
- **추천**: 저장공간이 부족하면 ~/Downloads 폴더 정리부터

## macOS 업데이트

- 시스템 설정 → 일반 → 소프트웨어 업데이트
- 자동 업데이트 켜두면 편하지만, 중요한 작업 전에는 꺼두는 게 안전

## 활성 상태 보기 (작업 관리자)

윈도우의 작업관리자에 해당하는 것.

- **Cmd + Space** → "활성 상태 보기" 검색
- CPU, 메모리, 디스크, 네트워크 사용량 확인
- 먹통인 앱 강제 종료 가능

간단하게 앱만 강제 종료하려면: **Cmd + Option + Esc**
