# 파인더 & 파일 관리

> 윈도우의 파일 탐색기에 해당하는 맥의 파인더

## 파인더 = 파일 탐색기

윈도우에서 폴더를 열면 "파일 탐색기"가 열리듯, 맥에서는 **Finder(파인더)**가 열린다.

## 윈도우 탐색기와 다른 점

| | 윈도우 탐색기 | 맥 파인더 |
|---|---|---|
| 잘라내기 | Ctrl + X → Ctrl + V | Cmd + C → **Cmd + Option + V** |
| 이름 변경 | F2 | **Enter** |
| 열기/실행 | Enter | **Cmd + 아래** 또는 더블클릭 |
| 경로 입력 | 주소창 클릭 | **Cmd + Shift + G** |
| 숨김 파일 | 폴더 옵션 | **Cmd + Shift + .** |
| 삭제 | Delete키 | **Cmd + Delete** |
| 미리보기 | 없음 | **Space** (Quick Look) |

> **가장 많이 실수하는 것**: 파인더에서 Enter 누르면 열리는 게 아니라 **이름이 바뀐다**!

## 파인더 필수 단축키

| 단축키 | 기능 |
|--------|------|
| Space | **Quick Look** - 파일 미리보기 (PDF, 이미지, 영상 다 됨) |
| Cmd + Shift + G | 경로 직접 입력해서 이동 |
| Cmd + Shift + . | 숨김 파일/폴더 보기/숨기기 |
| Cmd + Option + V | 이동 붙여넣기 (Cmd+C 후 사용) |
| Cmd + Delete | 파일 휴지통으로 보내기 |
| Cmd + 위 | 상위 폴더로 이동 |
| Cmd + 아래 | 폴더 열기 / 파일 실행 |
| Cmd + 1/2/3/4 | 보기 전환 (아이콘/목록/컬럼/갤러리) |

## Quick Look (스페이스바 미리보기)

맥의 숨겨진 보물 기능. 파일 선택 후 **Space**만 누르면 바로 미리보기가 뜬다.

- 이미지, PDF, 영상, 문서 다 지원
- 앱을 열지 않아도 바로 내용 확인
- 여러 파일 선택 후 Space 누르면 슬라이드쇼처럼 넘기기 가능

## 홈 폴더 (~) 구조

```
~/                          ← 홈 폴더 (/Users/storywinner)
├── Desktop/                ← 바탕화면
├── Documents/              ← 문서
├── Downloads/              ← 다운로드
├── Pictures/               ← 사진
├── Music/                  ← 음악
├── Movies/                 ← 동영상
├── Projects/               ← 민티 프로젝트 폴더 (직접 생성)
│   ├── claude-book/        ← 책 프로젝트
│   └── Sites/              ← 웹사이트 프로젝트
└── Applications/           ← 앱 (시스템은 /Applications)
```

## 파인더에서 경로 보기

기본적으로 파인더는 현재 어느 폴더에 있는지 경로를 안 보여준다.

**경로 바 켜기**:
- 파인더 메뉴 → 보기 → **경로 막대 보기** (Cmd + Option + P)

그러면 파인더 하단에 현재 경로가 표시된다.
