# 맥의 철학과 원리

> 윈도우에서 넘어온 사람이 알아야 할 맥의 핵심 차이점

## 맥과 윈도우, 근본적으로 뭐가 다른가

### 운영체제 기반이 다르다

- **윈도우**: Windows NT 기반
- **맥(macOS)**: Unix 기반 (리눅스와 친척)

이게 왜 중요하냐면, 터미널(명령어)을 쓸 때 **리눅스 명령어가 그대로 통한다**. 서버, 개발 환경과 같은 언어를 쓰는 셈이라, 개발 도구들이 맥에서 더 자연스럽게 돌아간다.

### 앱 설치 방식이 다르다

| | 윈도우 | 맥 |
|---|---|---|
| 설치 파일 | `.exe` 실행 → Next Next | `.dmg` 열기 → Applications로 드래그 |
| 삭제 | 제어판 → 프로그램 제거 | 앱을 휴지통에 드래그 (또는 AppCleaner) |
| 패키지 관리자 | 없음 (또는 winget) | **Homebrew** (터미널에서 한 줄로 설치) |

### 창 관리 철학이 다르다

- **윈도우**: 창을 닫으면 = 프로그램 종료
- **맥**: 창을 닫아도 (Cmd + W) ≠ 프로그램 종료. **Cmd + Q**를 눌러야 진짜 종료

맥은 "앱은 계속 살아있고, 창만 열고 닫는다"는 개념이다. Dock에 점이 찍혀있으면 아직 실행 중이라는 뜻.

> **예외: 파인더(Finder)는 Cmd+Q로 종료할 수 없다.** 파인더는 macOS의 핵심 앱이라 항상 살아있어야 한다. 윈도우의 탐색기(explorer.exe)가 꺼지면 바탕화면이 사라지는 것과 같은 이유. 파인더 창은 `Cmd + W`로 닫고, "열기/저장" 대화상자는 `Esc` 키로 닫는다.

| 상황 | 닫는 법 |
|---|---|
| 일반 앱 종료 | `Cmd + Q` |
| 파인더 창 닫기 | `Cmd + W` |
| 열기/저장 대화상자 | `Esc` 또는 취소 버튼 |

### 메뉴바가 앱 위에 있다

윈도우는 각 창 안에 메뉴가 있지만, 맥은 **화면 최상단 메뉴바가 현재 활성 앱의 메뉴**를 보여준다. 앱을 전환하면 메뉴바 내용도 바뀜.

## 키보드: 윈도우와 다른 점

### 키 이름 대응표

| 윈도우 | 맥 | 기호 |
|--------|-----|------|
| Ctrl | Command (Cmd) | ⌘ |
| Alt | Option | ⌥ |
| 윈도우키 | (없음, 비슷한 건 Cmd) | |
| Delete | Fn + Delete (뒤로 삭제) | |
| Backspace | Delete | ⌫ |

### Delete 키가 없다?!

맥 키보드에서 가장 헷갈리는 부분. 맥의 `Delete` 키는 윈도우의 `Backspace`다 (커서 왼쪽 삭제).

윈도우의 Delete처럼 **커서 오른쪽을 삭제**하려면:

```
Fn + Delete = 커서 오른쪽 삭제 (윈도우의 Delete)
```

### 왜 이름이 다를까?

**설계 철학의 차이**다.

- **윈도우(IBM PC)**: 풀사이즈 키보드에서 시작. 키가 넉넉하니까 `Backspace`(뒤로 지우기)와 `Delete`(앞으로 지우기)를 물리적으로 따로 만들었다.
- **애플**: 처음부터 심플한 디자인 추구. "지운다"는 동작에 키 두 개나 필요해? 하나로 충분하지! 기본 동작은 `Delete` 키 하나로, 반대 방향이 필요하면 `Fn` 조합으로 해결.

애플 입장에서는 "글자를 삭제(Delete)한다"가 핵심이고 방향은 부차적인 것. 그래서 그냥 `Delete`라고 이름 붙인 것이다. 윈도우는 "뒤로 간다(Back)"와 "삭제한다(Delete)"를 구분한 것.

**파일 삭제도 같은 맥락**: 윈도우에서 파일 삭제는 `Delete` 키 하나지만, 맥은 `Delete` 키에 여러 의미를 실었으니 파일 삭제 같은 위험한 동작에는 `Cmd + Delete` 조합을 붙여서 실수를 방지한다.

### 기타 키보드 차이

| 하고 싶은 것 | 윈도우 | 맥 |
|-------------|--------|-----|
| 복사 | Ctrl + C | Cmd + C |
| 붙여넣기 | Ctrl + V | Cmd + V |
| 잘라내기 | Ctrl + X | Cmd + X |
| 실행취소 | Ctrl + Z | Cmd + Z |
| 전체선택 | Ctrl + A | Cmd + A |
| 찾기 | Ctrl + F | Cmd + F |
| 저장 | Ctrl + S | Cmd + S |
| 작업관리자 | Ctrl+Shift+Esc | Cmd + Space → "활성 상태 보기" |
| 프로그램 전환 | Alt + Tab | Cmd + Tab |
| 강제 종료 | Ctrl+Alt+Delete | Cmd + Option + Esc |

**핵심 규칙**: 윈도우에서 Ctrl로 하던 거 → 맥에서는 Cmd로 하면 대부분 맞다.

## 파일 시스템: 경로가 다르다

| | 윈도우 | 맥 |
|---|---|---|
| 구분자 | `\` (역슬래시) | `/` (슬래시) |
| 홈 폴더 | `C:\Users\사용자명` | `/Users/사용자명` 또는 `~` |
| 프로그램 | `C:\Program Files` | `/Applications` |
| 바탕화면 | `C:\Users\...\Desktop` | `~/Desktop` |

`~` (틸드)는 **내 홈 폴더**를 뜻하는 축약어다. `~/Documents`는 `/Users/storywinner/Documents`와 같은 뜻.

## 맥에서 처음에 적응 안 되는 것들

1. **마우스 스크롤 방향이 반대** - 맥은 "자연스러운 스크롤" (터치스크린처럼 밀어올리면 위로 감). 시스템 설정에서 바꿀 수 있음
2. **최대화 버튼이 전체화면** - 초록 버튼이 윈도우의 최대화가 아니라 전체화면. Option 누르고 클릭하면 윈도우식 최대화
3. **파인더에서 잘라내기(Cmd+X)가 안 됨** - 대신 Cmd+C로 복사 후, **Cmd+Option+V**로 이동 붙여넣기
4. **경로 입력이 불편** - 파인더에서 **Cmd+Shift+G**로 경로 직접 입력 가능
5. **Home/End 키가 다름** - Cmd+좌/우 = 줄의 처음/끝, Cmd+위/아래 = 문서의 처음/끝
