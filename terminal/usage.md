# 터미널 사용법 (단축키 & 분할)

> 매일 쓰는 터미널/iTerm2의 실전 단축키와 분할 화면 활용법

## 터미널.app vs iTerm2 구분하는 법

맥에 기본 내장된 **터미널.app**과 따로 설치한 **iTerm2**는 겉모습이 비슷해서 헷갈리기 쉽다. 이렇게 구분하면 된다.

### 1. 메뉴바 좌상단 앱 이름 확인

화면 **맨 위 메뉴바 좌상단**에 앱 이름이 뜬다.
- `Terminal` → 기본 터미널
- `iTerm2` → iTerm2

### 2. 우상단 핫키 표시

iTerm2는 창 우상단에 **`⌥⌘1`** 같은 핫키 번호가 표시된다 (창 번호). 기본 터미널엔 없다.

### 3. Cmd + D 눌러보기

터미널 창에서 `Cmd + D`를 눌렀을 때:
- **분할 화면이 일어남** → iTerm2 ✅
- **아무 일도 안 일어남** → 기본 터미널

### 4. UI 차이

| | 터미널.app | iTerm2 |
|---|---|---|
| **상단 제목줄** | 두꺼운 회색 바 (큼직) | 얇고 깔끔 |
| **탭** | 단순한 사각형 | 둥글고 색깔 풍부 |
| **하단 상태바** | 거의 없음 | CPU/배터리/시간 표시 가능 |
| **분할 화면** | 안 됨 | 한 창을 2~4개로 분할 가능 |
| **검색** | 단순 | 정규식, 복사 기능 풍부 |

> **추천**: 클로드 코드 작업이 많다면 iTerm2로 통일! `iTerm2` 메뉴 → **Make iTerm2 Default Term** 클릭하면 시스템 기본 터미널이 iTerm2로 바뀐다.

## 분할 화면 활용 (iTerm2 전용)

iTerm2의 가장 강력한 기능. **한 창에서 여러 작업을 동시에** 할 수 있다.

### 분할 단축키

| 단축키 | 동작 |
|--------|------|
| **Cmd + D** | 좌우(세로) 분할 |
| **Cmd + Shift + D** | 위아래(가로) 분할 |

### 활용 예시

분할로 작업하면 한 화면에서 동시에 여러 일이 가능하다.

- **왼쪽**: 클로드 코드 작업
- **오른쪽**: `git status`, `ls` 등 명령어 직접 실행

여러 번 분할해서 4개 창까지 만들 수 있지만, **2~3개가 가장 작업하기 좋다**.

## 창 닫기 & 이동

### 닫기 단축키

| 단축키 | 동작 |
|--------|------|
| **Cmd + W** | 현재 분할 창 1개만 닫기 |
| **Cmd + Shift + W** | 전체 창(모든 분할 포함) 닫기 |
| **Cmd + Q** | iTerm2 앱 자체 종료 |

> 처음 `Cmd + W` 누르면 "정말 닫을까?" 확인창이 뜰 수 있다. Enter 또는 "Terminate" 클릭으로 진행.

### 새 창/탭 만들기

| 단축키 | 동작 |
|--------|------|
| **Cmd + N** | 새 창 열기 |
| **Cmd + T** | 새 탭 열기 (기존 창 안에) |

### 분할 창 사이 이동

| 단축키 | 동작 |
|--------|------|
| **Cmd + [** | 이전 분할 창으로 이동 |
| **Cmd + ]** | 다음 분할 창으로 이동 |
| **Cmd + Option + 화살표** | 방향대로 분할 창 이동 |

### 탭 사이 이동

| 단축키 | 동작 |
|--------|------|
| **Cmd + 숫자** | 해당 번호 탭으로 이동 (Cmd + 1 ~ Cmd + 9) |
| **Cmd + Shift + [** | 이전 탭 |
| **Cmd + Shift + ]** | 다음 탭 |

## 자주 쓰는 편집 단축키

터미널에서 명령어 작성할 때 쓸 수 있는 단축키.

| 단축키 | 동작 |
|--------|------|
| **Ctrl + A** | 줄 맨 앞으로 커서 이동 |
| **Ctrl + E** | 줄 맨 뒤로 커서 이동 |
| **Ctrl + U** | 커서 앞 전체 삭제 |
| **Ctrl + K** | 커서 뒤 전체 삭제 |
| **Ctrl + W** | 단어 하나 삭제 |
| **Ctrl + L** | 화면 깔끔히 비우기 (`clear`와 동일) |
| **Ctrl + C** | 실행 중인 명령 취소 |
| **Ctrl + R** | 이전 명령어 검색 (입력하면 매칭되는 명령어 찾기) |
| **위/아래 화살표** | 이전/다음 명령어 불러오기 |

## 폰트 크기 조절

화면을 크게 보고 싶거나 강의용으로 띄울 때 유용.

| 단축키 | 동작 |
|--------|------|
| **Cmd + +** | 폰트 키우기 |
| **Cmd + -** | 폰트 줄이기 |
| **Cmd + 0** | 기본 크기로 |

## 실전 워크플로우 예시

### 1) 클로드 코드 작업 + 명령어 실행

```
1. 프로젝트 폴더에서 우클릭 → "New iTerm2 Window Here"
2. 클로드 코드 실행: claude
3. Cmd + D로 좌우 분할
4. 오른쪽에서 git status, ls 등 명령어 실행
```

### 2) 여러 프로젝트 동시 작업

```
1. iTerm2 새 창 열기 (Cmd + N)
2. 첫 번째 창에서: cd ~/Projects/dailybook → claude
3. Cmd + N으로 두 번째 창 열기
4. 두 번째 창에서: cd ~/Projects/storywinner → claude
5. Cmd + Tab으로 창 사이 전환
```

> **꿀팁**: iTerm2 창이 여러 개일 때 우상단의 `⌥⌘1`, `⌥⌘2` 같은 핫키 번호로 빠르게 전환 가능!
