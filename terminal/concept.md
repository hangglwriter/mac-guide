# 터미널이란?

> 컴퓨터에게 글자로 명령을 내리는 창

## 쉽게 말하면

일반적으로 컴퓨터를 쓸 때는 마우스로 아이콘을 클릭한다. 터미널은 **마우스 대신 글자(명령어)로 컴퓨터에게 지시하는 창**이다.

비유하면:
- **일반 사용** = 식당에서 메뉴판 보고 손가락으로 가리키기
- **터미널** = 식당에서 직접 말로 주문하기 ("된장찌개 하나, 밥 곱빼기로")

말로 주문하면 메뉴판에 없는 것도 요청할 수 있듯, 터미널은 마우스 클릭으로 못하는 것도 할 수 있다.

## 왜 터미널을 쓰나?

1. **마우스로 못 하는 것을 할 수 있다** - 시스템 깊숙한 설정, 자동화
2. **반복 작업이 빠르다** - 클릭 10번 할 걸 명령어 한 줄로
3. **개발 도구가 터미널 기반** - Git, Homebrew, Claude Code 등
4. **클로드코드가 여기서 돌아간다** - 이게 민티한테 가장 큰 이유!

## 터미널 vs iTerm2

| | 터미널 | iTerm2 |
|---|---|---|
| 제공 | macOS 기본 내장 | 별도 설치 |
| 기능 | 기본적 | 탭 분할, 검색, 자동완성 등 |
| 추천 | 입문용 | 실제 작업용 |

둘 다 "명령어를 입력하는 창"이라는 점은 같다. iTerm2가 더 편해서 쓰는 것.

## 쉘(Shell)이란?

터미널은 "창"이고, **쉘은 그 안에서 명령어를 해석하는 프로그램**이다.

- 비유: 터미널 = 전화기, 쉘 = 전화 상담원
- 맥의 기본 쉘: **zsh** (Z Shell)
- 터미널을 열면 `storywinner@MacBookAir ~ %` 같은 게 보이는데, 이게 zsh이 "명령어 받을 준비 됐어"라고 알려주는 것

## 프롬프트 읽는 법

```
storywinner@seutoliwineoui-MacBookAir ~ %
│              │                       │ │
│              │                       │ └─ 여기에 명령어 입력
│              │                       └─── 현재 위치 (~ = 홈폴더)
│              └───────────────────────── 컴퓨터 이름
└──────────────────────────────────────── 사용자 이름
```
