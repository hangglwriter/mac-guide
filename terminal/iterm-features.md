# iTerm2 주요 기능

## 웹 브라우저 기능

> iTerm2 3.6.9부터 터미널 안에서 웹페이지를 볼 수 있다

### 브라우저 플러그인 설치

1. [iTerm2 공식 사이트](https://iterm2.com/)에서 Browser Plugin 다운로드
2. zip 압축 해제 → `iTermBrowserPlugin.app`을 Applications로 이동

### 웹 프로필 설정

1. iTerm2 → Settings (Cmd + ,)
2. Profiles 탭
3. 왼쪽 하단 `+`로 새 프로필 추가
4. General → Profile Type을 **Web Browser** 선택
5. "Browser Plugin Installed" 초록 체크 확인

### 웹 프로필로 열기

- 상단 메뉴 **Profiles** → 만든 웹 프로필 클릭
- 또는 Cmd + O → 프로필 목록에서 선택

### 웹 브라우저 단축키

| 단축키 | 기능 |
|--------|------|
| Cmd + 클릭 | 새 탭에서 링크 열기 |
| Cmd + Shift + 클릭 | 세로 분할 창에서 열기 |
| Cmd + Shift + Option + 클릭 | 가로 분할 창에서 열기 |
| Cmd + [ | 뒤로가기 |
| Cmd + ] | 앞으로가기 |
| Cmd + F | 페이지 내 검색 |

### 웹 브라우저 설정 옵션

- **Ad Blocker** - 광고/추적기 차단. 켜는 걸 추천
- **Instant Replay** - 화면 녹화 되감기. 잘 안 쓰면 꺼둬도 됨

### Ask AI 기능

웹페이지를 보면서 AI에게 질문할 수 있는 기능. 햄버거 메뉴(≡) → Ask AI.
단, **OpenAI API 키가 필요**하다. 이미 클로드코드를 쓰고 있다면 굳이 설정할 필요 없음.

### 실전 활용도

솔직히 웹 브라우징은 크롬/사파리가 더 편하다. 터미널 작업 중 문서를 잠깐 확인할 때 유용하지만, 평소에는 Default 프로필(터미널)로 쓰는 게 좋다.
