# 실전 팁 & 트러블슈팅

> 자주 겪는 문제와 해결법, 알아두면 좋은 팁

## 광범위한 작업은 에이전트 여러 명에게 병렬 분담

큰 작업(자료 60개 검증, 파일 100개 분석 등)을 한 에이전트에게 시키면 시간이 오래 걸려. 대신 **여러 에이전트에게 나눠서 동시에 시키면** 시간이 1/N로 줄어.

### 왜 빠른가
- 한 에이전트는 순차 처리: 작업1 → 작업2 → ... → 작업N
- 여러 에이전트 병렬: 작업1·2·3·4 동시
- 100개 명함 혼자 정리 1시간 → 4명 동시에 15분

### 어떻게 시키나
- "Q1~Q5는 A에게, Q6~Q10은 B에게" 처럼 **겹치지 않게** 영역 분배
- 각 에이전트에게 "다른 사람 영역 건드리지 마" 명시
- 한 메시지에 여러 Agent 호출 → 진짜 동시 실행 (순서대로 호출하면 순차 처리됨)
- 백그라운드로 띄우면 결과 기다리는 동안 다른 작업 가능

### 실전 예시 (자서전 책 출처 검증)
- 출처 60개를 한 에이전트로 처리 → 1시간+
- 4명에게 분담 (Q1~2 / Q3~4 / Q5~7 / Q8~10) 동시 → 15분
- 결과 받아서 통합 보고만 하면 끝
