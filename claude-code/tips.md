# 실전 팁 & 트러블슈팅

> 자주 겪는 문제와 해결법, 알아두면 좋은 팁

## 광범위한 작업은 에이전트 여러 명에게 병렬 분담

큰 작업(자료 60개 검증, 파일 100개 분석 등)을 한 에이전트에게 시키면 시간이 오래 걸려. 대신 **여러 에이전트에게 나눠서 동시에 시키면** 시간이 1/N로 줄어.

### 왜 빠른가
- 한 에이전트는 순차 처리: 작업1 → 작업2 → ... → 작업N
- 여러 에이전트 병렬: 작업1·2·3·4 동시
- 100개 명함 혼자 정리 1시간 → 4명 동시에 15분

### 어떻게 시키나
- "Q1~Q5는 A에게, Q6~Q10은 B에게" 처럼 **겹치지 않게** 영역 분배
- 각 에이전트에게 "다른 사람 영역 건드리지 마" 명시
- 한 메시지에 여러 Agent 호출 → 진짜 동시 실행 (순서대로 호출하면 순차 처리됨)
- 백그라운드로 띄우면 결과 기다리는 동안 다른 작업 가능

### 실전 예시 (자서전 책 출처 검증)
- 출처 60개를 한 에이전트로 처리 → 1시간+
- 4명에게 분담 (Q1~2 / Q3~4 / Q5~7 / Q8~10) 동시 → 15분
- 결과 받아서 통합 보고만 하면 끝

## 큰 의사결정은 "관점별 에이전트"로 다각도 검토

분담의 또 다른 응용. 차 처분, 이사, 큰 구매 같은 **인생 의사결정** 앞에서 에이전트를 "관점별로" 띄우면 사각지대 줄여줘.

### 왜 효과적인가
- 한 에이전트는 한 논리 흐름으로 결론 내기 쉬움 → 한쪽으로 치우침
- 관점별 에이전트는 **자기 관점만 끝까지 파고들어** 결과를 줌
- 마지막에 4~8개 결과를 비교하면 "모든 관점이 같은 방향"인지 "관점마다 답이 다른 회색지대"인지 보여
- 모든 관점이 같은 방향 = 결정 확신 높아짐

### 어떻게 시키나
- 결정에 영향 미치는 **관점을 4~8개로 분해**
  - 차 처분 결정 예: 안전성 / 경제성 / 대안 차량 / 정책·타이밍 / 검사 통과 가능성 / 처분 옵션
- 각 에이전트에게 **"네 관점만 끝까지 파"** 명시 ("다른 관점은 다른 사람이 봐")
- 에이전트마다 **출처 URL 명시** 요구 → 팩트체크 가능
- 한 메시지에 여러 Agent 동시 호출 (순차 X)
- 결과 다 모이면 **"모두 같은 방향이 가리키는가"** 체크

### 실전 예시 (차 처분 결정)
- 안전성 에이전트: "다음 출장은 이 차로 가지 마" (안전 위험 큼)
- 경제성 에이전트: "수리 견적 350만 넘으면 폐차 우위"
- 대안 차량 에이전트: "그랜저 하이브리드 1순위"
- 정책·타이밍 에이전트: "6/30 신차 개소세 마감"
- 검사 통과 에이전트: "현 상태 통과율 20~30%"
- 처분 옵션 에이전트: "수출이 폐차보다 2~3배 더 받음"
- → **모든 관점이 "처분 + 갈아타기" 방향** = 결정 확신
- 6개 결과 통합해서 단계별 액션 플랜 도출

### 추가 팁
- 결정 흔들릴 때 **반대 가설 검증 에이전트** 1명 더 띄우기 ("이 결정이 틀렸다면?")
- 사실 기반 결정이면 **팩트체크 에이전트**로 1차 자료 검증 (CLAUDE.md 팩트체크 시스템과 결합)

## AI가 찾아준 자료는 "그럴듯하게" 틀린다 → 책에 넣을 건 원문으로 확인

AI(클로드 포함)나 인터넷 검색은 **확신에 찬 목소리로 틀린 사실을 말할 때가 많다.** 특히 ① 명언이 누구 말인지 ② 숫자·나이·연도 ③ "누가 언제 무엇을 했다"는 일화. 이걸 그대로 책·콘텐츠에 넣으면 망신이다.

### 왜 위험한가
- AI는 "그럴듯한 문장"을 만드는 도구라, 빈칸을 **자신 있게 지어내서** 채울 수 있다 (이걸 할루시네이션이라 부름)
- 블로그·요약 기사·나무위키는 서로 베껴서 **같은 오류가 사방에 퍼져** 있음 → 여러 군데서 똑같이 나와도 사실이 아닐 수 있다

### 책·콘텐츠에 넣기 전 체크 (실전 규칙)
- **1차 출처로만 확정**: 위키백과 / 한국민족문화대백과 / 신문 원문 / 공식 연설 전문 / 책 원문. (블로그·나무위키·요약은 "참고만", 단정 금지)
- AI에게 시킬 때 이렇게 못 박기:
  - "**URL을 지어내지 말고, 실제로 연 페이지만** 알려줘"
  - "발언·일화는 **원문 그대로** 따옴표로 인용"
  - "1차 출처로 확인 안 되면 **⚠️ 표시**하고 단정하지 마"
  - "**확인 안 되는 구체적 장면은 지어내지 마**"
- 마지막에 **팩트체커 에이전트 한 명을 따로 띄워** 원고의 인용·숫자·연도를 한 줄씩 대조 (직접 인용은 글자까지)

### 실전 예시 (자서전 책 2·3장에서 잡은 오류들)
- "사람들은 어떤 느낌을 줬는지는 안 잊는다" → **마야 안젤루 말이 아니라** 다른 사람 말이었음
- 모지스 할머니가 그림 시작한 나이 76세 → 실은 **78세** (76세는 관절염 시작 시점)
- 정주영이 "부둣가에서 흙 날랐다" → 흙은 **철도 공사판**, 부둣가는 막일 (장소가 섞임)
- 박노갑 선생님이 박완서에게 영향 줬다 → 박완서 본인이 인정한 **1차 기록이 없었음** → 단정 안 하고 검증되는 사실로만 다시 씀
- 한비야 제주 여행이 "스무 살" → 실은 **고3 졸업 직후(18세)**
- → 교훈: **그럴듯해 보일수록 원문 확인.** 안 되는 건 빼거나 "전해진다"로 완충
