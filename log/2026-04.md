## 4/28 - Gmail MCP 커넥터 활용 & 이메일 워크플로우 정립

### 한 일

- 답신 초안이 Gmail 임시보관함에서 안 보이는 동기화 이슈 발견 → 해결책 마련
- 이메일 답신 워크플로우 정립 (텍스트 초안 → 검토 → Zapier 발송)
- `~/Projects/email/` 폴더 활용 규칙 메모리 저장
- 맥 폴더 우클릭 → 터미널 열기 활성화 방법 학습

### 배운 것
- **MCP(Model Context Protocol) = 클로드의 USB**: Gmail, Notion, Zapier 같은 외부 서비스를 클로드와 연결하는 표준 규격. 한번 연결해두면 클로드가 그 앱을 직접 조작 가능
- **claude.ai Gmail vs Zapier Gmail 차이**:
  - claude.ai Gmail: `create_draft`만 가능 (답글 전용 기능 X), 안전하게 초안만 생성
  - Zapier Gmail: `gmail_create_draft_reply` 가능 (원본 스레드에 답글로 연결), `gmail_send_email`로 직접 발송도 가능
- **답신 초안의 함정**: Zapier로 만든 답글 초안이 Gmail UI에서 안 보일 수 있음 (답글 헤더 호환성 이슈) → 해결: 답글 형식보다 새 메일 형태로 만들면 임시보관함에 안정적으로 표시
- **맥의 "서비스" 메뉴**: 시스템 설정 → 키보드 → 단축키 → 서비스에서 활성화. 윈도우의 우클릭 확장 기능과 동일. 폴더 우클릭으로 터미널 열기, 텍스트 처리 등 다양한 기능 사용 가능
- 이메일은 텍스트 초안 단계에서 충분히 다듬은 후 Gmail로 보내는 게 더 안정적

- [터미널 사용법 (단축키 & 분할)](/terminal/usage) - 신규 작성. 터미널/iTerm2 구분법, 분할 단축키, 창 닫기/이동, 편집 단축키 등 실전 사용법 정리

### 오늘의 꿀팁
- **MCP 커넥터 = 클로드의 USB**: 외부 앱을 클로드에 연결하는 표준 규격. `/mcp`로 연결 관리. 한 번 연결하면 메일 검색, 초안 작성, 라벨 관리까지 클로드가 직접 처리.
- **맥 미니멀리즘 vs 윈도우 직관성**: 맥은 기능을 "서비스"라는 비밀 창고에 숨겨두고 사용자가 꺼내 쓰게 함. 윈도우는 처음부터 다 꺼내놓음. 맥에서 윈도우 같은 편의 기능 찾을 땐 시스템 설정의 "서비스" 메뉴 확인!

## 4/27 - 엣지 설치 & DNS 변경으로 인터넷 속도 개선

### 한 일
- Homebrew로 Microsoft Edge 설치 (`brew install --cask microsoft-edge`)
- 엣지에서 인터넷 느린 원인 진단 → 보안 DNS(DoH) 설정이 원인이었음
- 엣지 설정에서 보안 DNS를 Cloudflare(`https://1.1.1.1/dns-query`)로 변경 → 빨라짐
- 시스템 전체 DNS도 Cloudflare + Google로 변경 (모든 앱이 빨라짐)

### 배운 것
- **DNS는 인터넷 전화번호부.** 도메인(naver.com)을 IP 주소로 변환해주는 역할
- 기본 DNS는 인터넷 회사(KT/SKT/LG) 서버 → 가끔 느림
- Cloudflare(`1.1.1.1`)는 무료 + 가장 빠른 DNS 중 하나
- 시스템 DNS를 바꾸면 크롬, 사파리, 엣지, 앱스토어 등 **모든 앱이 빨라짐**
- 브라우저별로 자체 DoH(보안 DNS) 설정이 따로 있어서 시스템과 충돌 가능
- 명령어 한 줄로 설정 가능: `networksetup -setdnsservers Wi-Fi 1.1.1.1 1.0.0.1 8.8.8.8 8.8.4.4`
- 인터넷 느림 진단 3단계: ① 전체 느림(네트워크/DNS) ② 특정 브라우저(확장/캐시/DoH) ③ 특정 사이트(쿠키/계정/서버)

- 파인더는 Cmd+Q로 종료 불가 (macOS 핵심 앱) 이해

- 파인더 태그 기능 학습 (파일에 색깔 스티커 붙이는 분류 시스템)
- 맥에서 한글(HWP) 무료 작업 방법 조사 → 한컴독스 웹 추천

### 배운 것
- 맥의 Delete = 윈도우의 Backspace. 애플은 "키 하나 + 조합키"로 미니멀하게, 윈도우는 "키 여러 개"로 직관적으로 설계한 철학 차이
- 파인더는 종료 불가 앱. 창 닫기(Cmd+W)와 앱 종료(Cmd+Q)를 구분해야 함
- 태그 = 폴더와 다른 개념. 여러 폴더에 흩어진 파일을 태그로 묶어서 볼 수 있음
- HWP 무료 편집은 한컴독스 웹(docs.hancom.com)이 사실상 유일한 실용적 선택
