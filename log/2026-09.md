# 2026년 9월

## 9/11 - 갤럭시 미러링 세팅 (scrcpy) + 클릭 실행 앱 만들기

### 한 일
- 맥북에 **scrcpy + adb 설치 확인** (이미 설치돼 있었음: scrcpy 3.3.4)
- 갤럭시 S24 울트라(SM-S928N, Android 16) **개발자 옵션 → USB 디버깅 → 연결까지 완료**
- **한글 입력이 안 되는 문제 원인 규명**: 기본 `sdk` 모드는 안드로이드 키 배열표에 있는 문자만 넣을 수 있어서 한글 불가 → `--keyboard=uhid` 모드 / 클립보드 복붙(`MOD+v`)으로 우회
- **터미널 없이 클릭으로 실행되는 앱 제작**: `~/Applications/휴대폰미러링 (scrcpy).app`
  - 폰 연결 상태를 먼저 확인하고, 문제가 있으면 원인별 안내창을 띄우도록 작성
  - 스포트라이트에서 "휴대폰", "미러", "scrcpy" 무엇으로 검색해도 나오게 이름 설계
- **USB를 그냥 뽑아도 되는지 확인**: 폰이 디스크로 마운트되지 않아서 "안전하게 제거" 절차 불필요함을 `ls /Volumes/`로 검증

### 배운 것
- **"안 된다"는 로그에 이유가 적혀 있다**: 한글이 안 써질 때 그냥 포기하지 않고 터미널 로그를 보니 `Could not inject char u+c548`('안') 이 찍혀 있었다. 증상("한글이 안 돼")이 아니라 원인("이 글자를 못 넣는다")이 보이면 해결책이 바로 나온다
- **맥은 손으로 조립한 앱을 믿지 않는다**: 폴더 구조를 직접 만들고 셸 스크립트를 넣는 방식은 `-10669`(실행 권한 없음)로 막혔다. 애드혹 서명을 붙여도 동일. `osacompile`로 만들어야 macOS가 인정하는 정식 앱이 된다
- **USB 안전 제거의 기준은 "디스크로 붙었는가"**: 파일 저장소로 마운트됐을 때만 필요하다. 미러링은 디버깅 통로만 쓰므로 그냥 뽑아도 된다 ([스마트폰 미러링](/mac/mirroring) 참고)
- **스포트라이트는 파일 이름으로 찾는다**: 앱 이름에 검색할 만한 단어를 미리 넣어두면(`휴대폰미러링 (scrcpy)`) 한글·영문 어느 쪽으로 쳐도 걸린다

### 오늘의 꿀팁
- **"안 돼"에서 멈추지 말고 로그를 봐라**: 프로그램이 조용히 실패하는 것 같아도 대부분 터미널에 이유를 적어두고 있다. 그 한 줄을 AI에게 그대로 붙여주면 해결 속도가 몇 배 빨라진다. "한글이 안 써져"보다 "`Could not inject char u+c548` 이라고 떠"가 훨씬 강력한 질문이다
- **USB를 그냥 뽑아도 되는지 판단하는 법**: 터미널에 `ls /Volumes/` 를 쳐보면 된다. 거기 그 기기가 **보이면** 파일 저장소로 붙은 것이니 안전하게 제거(꺼내기)를 하고, **안 보이면** 그냥 뽑아도 된다. 윈도우의 "하드웨어 안전하게 제거"가 필요한 상황인지 아닌지를 눈으로 확인하는 방법
